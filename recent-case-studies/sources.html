Visual identity reference

The web presentation follows each client’s documented type and colour system. Pulse’s supplied 2025 vector identifies the agency navigation; project names in the gallery use their original artwork.

  • Robotist: robotist-brand-system\robotist-brand-guide.html for Poppins weights, positive letter-spacing, the navy/blue palette and #F0F4F8 light applications. Display: Medium, 0.20em. Section headings: Light, 0.06em. Reveal timing follows the guide’s 600ms page / 320ms control rhythm. The GSAP interpolation is a portfolio adaptation.
  • NeoLabCare: neolabcare bi 20260323.html, default sand-gold direction, reconciled with the existing landing-page type system. Poppins Medium with Noto Serif Display italic, #0A0A0A, off-white and #C8B89A. Gold remains emphasis, rules and labels, never a large digital surface. Secondary text follows the source off-white at 52% opacity.
  • Vodkiss: original identity deck, slides 19–20. Five core colours plus the explicitly drawn pale tints. Cinzel Decorative Black, Aboreto and Tw Cen MT. Assigning Aboreto to web headings and Tw Cen MT to the interface is a portfolio application of those source families, not a separately approved web type manual.
  • WeKwikGene: the existing approved page is unchanged. Its gallery entry now uses the original combined logo and the 2024 case palette, not substitute type or approximate colours.

Robotist and NeoLabCare remain active systems. These are the documented references used for this correction, not a claim that every historical asset is the final approved version.

Presentation system

Editorial chapter structure, original project imagery and typography, GSAP/ScrollTrigger and Lenis. The existing WeKwikGene interaction approach informed this edition. Only Lenis provides optional smooth scrolling. Touch devices use native scrolling; reduced-motion preferences disable choreography and ambient playback. No live 3D renderer or new generated imagery is used.

Every artwork can open at full size. Film controls remain available. Without JavaScript, all visual variants stay visible and image links open their source files. This preview runs entirely from local files and makes no analytics, form-submission or external tracking requests.

Publication checklist

  • Approve final copy, project state, scope and contributor credits.
  • Confirm client permission and image, manufacturer, illustration, film and font rights.
  • Check the selected assets are the intended final versions.
  • Remove or independently verify any claim proposed for public copy.
  • Adapt to the final website’s navigation and publishing workflow.
