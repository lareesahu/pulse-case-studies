## Required check before extending the collection

1. Locate and inspect the actual VI and applications, including font roles, weights, spacing, palette tints, mark variants, clear space and imagery. Record the selected version. A recent timestamp is not approval.
2. Keep neutral agency navigation separate. Do not let shared component defaults override client VI. Inspect captions, buttons, links, galleries, selected states and mobile layouts as well as hero sections.
3. Reuse original marks and artwork. Never reconstruct a logo using a similar typeface. Keep proposed, historical and final applications explicitly distinguished.
4. Label new layout/motion choices as web adaptations where the source does not prescribe them. Ask before making a new identity decision that cannot be resolved from evidence.
5. Run the source check and inspect computed styles in a real browser. Check actual font loading, wrapping, image proportions, reduced motion and interactive states. A build or passing file check is insufficient.

Source files were not changed. Public font and artwork rights, contributor credits and final client/brand versions still require approval before publishing.
